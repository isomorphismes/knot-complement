# Videos 2

## Geometry Center: primary archive

Start here:

- **Geometry Center Videos, Revisited — Tamara Munzner**
  https://www.cs.ubc.ca/~tmm/gc/

The archive contains the flagship films plus digitized research/student tapes and good timestamps.

### Not Knot (1991)

A foundational reference for this repository: knots -> complementary spaces -> hyperbolic geometry.

- Remastered direct upload:
  https://youtu.be/QcLfb0PhfO0
- Geometry Center background page:
  http://www.geom.uiuc.edu/video/NotKnot/

### The Shape of Space (1995)

Finite but unbounded spaces, including explicit spaceship/fly-through imagery. Based on Jeff Weeks's work.

- https://youtu.be/-gLNlC_hQ3M
- Background page:
  http://www.geom.uiuc.edu/video/sos/

### Outside In (1994)

Not itself a fly-through project, but important as an example of the Geometry Center/Thurston visualization culture.

- Tamara Munzner upload:
  https://www.youtube.com/watch?v=IbGNZQvobkc

## Non-Euclidean VR / Thurston geometries

### Non-euclidean virtual reality using ray marching — Henry Segerman

- https://youtu.be/ivHG4AOkhYA

Demonstrates real-time first-person movement in negatively curved 3-space. The associated code was designed to work in a browser and had mobile support.

### Henry Segerman real-time graphics / VR index

- http://www.segerman.org/XR.html

This collects the hyperbolic, Nil, Sol, cohomology-fractal, and eight-Thurston-geometry work.

### Portals to Non-Euclidean Geometries — ZenoRogue

- https://www.youtube.com/watch?v=yqUv2JO2BCs

Useful as a comparative tour through several geometries from the HyperRogue side.

## HyperRogue

HyperRogue is worth keeping in the video/game reference pile because it has implemented three-dimensional Thurston geometries and explicitly experiments with how geometry changes game mechanics.

- Thurston geometry update / embedded demonstrations:
  https://zenorogue.itch.io/hyperrogue/devlog/99827/hyperrogue-112-thurston-geometries-free-update
- Geometry reference page:
  https://roguetemple.com/z/hyper/geoms.php
